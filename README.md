# have-fun-dont-die

A sourced, evidence-marked notebook on aging biology and longevity tactics, built and maintained by AI research agents. Every claim carries a citation and a mark for how solid it is. Published papers, preprints, forum protocols, and wild speculation all go in, labeled so you can tell them apart.

You don't read it cover to cover. You point an agent at it and ask questions. When the answer is not written yet, the agent goes and researches it.

- **Ask a question:** [HOW_TO_ASK_AGENTS_QUESTIONS.MD](HOW_TO_ASK_AGENTS_QUESTIONS.MD) (Cursor, Cursor Agent CLI, or Claude Code)
- **See how it works:** [HOW_DOES_THIS_THING_WORK.md](HOW_DOES_THIS_THING_WORK.md)
- **Browse:** [hallmarks](#hallmarks) · [topics](#topics) · [compounds](#compounds) · [by tactic](#by-tactic) · [live fights](#live-fights) · [harms and bad claims](#harms-and-bad-claims)

Aging is the demo subject. The workflow works for any research topic.

## Not medical advice

This is not medical advice, a protocol, or a clinic. It documents what is known, what is guessed, and what people are actually running. A dose in these files is observed practice, not an instruction. We do not recommend for or against anything, with one exception: anything marked ☠︎︎ is established harm, and the advice is stay away.

## Evidence marks

Every claim in a report starts with one of these.

| Mark | Meaning |
|---|---|
| 💯 | Settled. Textbook consensus, no live dispute. Rare. |
| 📚 | Peer-reviewed paper supports it. |
| 📜 | Preprint. Not peer-reviewed yet. |
| 🥼 | Papers disagree. Both sides cited. |
| 🤔 | Forum, clinic, or self-experimenter practice. Makes sense, not known false. |
| 🤼 | Biohackers disagree. Forum threads cited. |
| ⛔ | Suspect. Implausible or already contradicted. |
| ☠︎︎ | Established harm. Stay away. |
| 🐉 | Wild speculation. Says what the leap stands on. |

Full rules: [AGENTS.md](AGENTS.md#evidence-marks).

## Topics

Protocols, procedures, technologies, and rumors that aren't a single molecule. Catalog: [topics/README.md](topics/README.md).

<!-- BEGIN GENERATED: root-topics -->
- [crispr](topics/crispr/report.md) — RNA-guided Cas plus host repair (or a fused deaminase/RT) writes a genotype distribution; Casgevy is one ex vivo HSPC product, liver LNP is not whole-body rewrite, and no CRISPR aging RCT was found.
- [enamel-remineralization-gel](topics/enamel-remineralization-gel/report.md) — The 2025–2026 enamel-regrowth gel is several SKUs: Hasan 2025 ~10 μm extracted-tooth ELR film (Epinamel, no in-mouth results), chairside P11-4/Curodont (live RCT fight vs fluoride), and consumer nano-HA / CPP-ACP pastes.
- [salamander-like-regeneration](topics/salamander-like-regeneration/report.md) — 2026 PNAS: conserved SP6/SP8 plus zebrafish-LEN FGF8 AAV partially rescues or speeds mouse P3 digit bone; not a salamander-gene transplant and not whole-limb regeneration.
- [bioelectricity](topics/bioelectricity/report.md) — Levin-lab ion-channel mRNA, pump drugs, and GJ block change frog/planaria anatomy (7.5% complete ectopic eyes; 25% octanol two-heads); BioDome is silk+5 drugs, not a voltage-dye rewrite; aging is a 2024 perspective plus keratinocyte dish, not a human Vmem trial.

## Contributing

The agents make mistakes. When a miss traces back to a skill, rule, or agent config, fix that file (`/self-improve`) so it doesn't happen again. Send one fix per PR, with an example of it failing before the fix and working after.

Use the strongest model you have for analysis. Cheap models are fine for fetching and scraping. Many cheap agents reading a few papers each beat one expensive agent reading one.

Adding a topic or compound: [AGENTS.md](AGENTS.md#adding-a-topic-or-compound). The tables above are generated by `python3 scripts/build-index.py` from [`scripts/index-meta.yaml`](scripts/index-meta.yaml); don't hand-edit the generated blocks.
