# Nelson and Makielski, 1991. Block of sodium current by heptanol in voltage-clamped canine cardiac Purkinje cells. Circulation Research.
https://doi.org/10.1161/01.res.68.4.977 PMID 1849060
Used for: n-Alkanols used as GJ uncouplers also block INa; octanol half-block ~0.29 mM in squid axon (cited therein).
Mark: 📚
N / effect / population / endpoint / duration: Canine Purkinje cells; 1–3 mM heptanol; n=5–6 for availability/activation shifts (+9.4 mV inactivation, +8.3 mV activation at 3 mM). Acute voltage clamp. Authors note these alcohols affect INa at concentrations used for uncoupling.
Conflict if any: Academic cardiac electrophysiology.
Methods / why the claim fails or is narrower than the slogan: “GJ blocker = voltage-network edit” assumes octanol’s relevant action is gap-junctional. INa and other nonjunctional blocks are documented for the same chemical class. Durant’s 127 µM is below the classic 0.29 mM squid IC50 but in the same dirty-alkanol neighborhood; cannot treat the phenotype as voltage-software by default.
