# Ismail AI et al., 2007. The International Caries Detection and Assessment System (ICDAS): an integrated system for measuring dental caries. Community Dentistry and Oral Epidemiology.
https://doi.org/10.1111/j.1600-0528.2007.00347.x
Used for: 📚 ICDAS is a visual ordinal caries code (0 sound; 1 first change after drying; 2 distinct change when wet; 3 localized enamel breakdown; 4 dentin shadow; 5–6 cavities), not a mineral-mass or crown-thickness assay.
Mark: 📚
N / effect / population / endpoint / duration: Consensus detection system. Codes describe visual appearance after cleaning/drying. White-spot class is codes 1–2 (subsurface porosity), not missing cusps. vVARDIS FAQ maps Repair to ICDAS 1–3 and says ICDAS 3 microcavities should not be expected to “fill.”
Conflict if any: None. System paper.
