# 📚 Published and peer-reviewed.

A real paper or review supports the statement, and that specific finding is not currently in a serious fight.

A document lives here because the **claim** in `report.md` is marked 📚. Do not promote a preprint because the authors are famous. Do not upgrade a paper to 💯 because it landed in a prestige journal.

## What belongs here

Journal papers and reviews that support an uncontested published finding.

PDFs, html, publisher pages, and markdown notes of those papers.

## What does not belong here

- Textbook-grade, uncontested facts (rare; not a single paper) → [💯](../💯/)
- Preprints (bioRxiv, medRxiv, arXiv, and the like) → [📜](../📜/)
- Papers in a live fight, published or preprint → [🥼](../🥼/)
- Forums, clinics, newsletters, podcasts, self-experiments, protocols-in-the-wild → [🤔](../🤔/)
- Amateur / biohacker disagreements. Never research papers → [🤼](../🤼/)
- Circulating claims that do not make sense → [⛔](../⛔/)
- Wild speculation → [🐉](../🐉/)

## File names

Short and source-identifying: `Author-Year-short-slug.ext` (or equivalent). Example: `Cagan-2022-somatic-mutation-rate-lifespan.pdf`.
