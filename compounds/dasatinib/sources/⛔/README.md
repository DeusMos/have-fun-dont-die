# ⛔ Suspect. Does not make sense.

The claim is circulating but is biologically implausible, internally inconsistent, or already contradicted. Cite the claim *and* why it fails. Nonsense without established meaningful harm stays here. If we are sure it hurts people in a real way, that is ☠︎︎, not ⛔.

A document lives here because the **claim** in `report.md` is marked ⛔. Include the circulating claim and the falsifier. Clinic marketing with a garbage mechanism lands here, not in 🤔.

## What belongs here

The claim as circulated (forum post, clinic page, newsletter, paper-as-cited-in-the-wild) **and** the source that shows it fails (paper, trial, contradiction). PDFs, html, markdown notes. Do not file only the hype.

## What does not belong here

- Settled textbook facts → [💯](../💯/)
- Uncontested published findings → [📚](../📚/)
- Preprints that are real manuscripts, not already known-false → [📜](../📜/)
- Live research disagreement (both sides still plausible) → [🥼](../🥼/)
- Mechanistically coherent internet/clinic practice, not known-false → [🤔](../🤔/)
- Amateur fight where the mechanism is not garbage → [🤼](../🤼/)
- Known meaningful harm — sure it hurts people in a real way, not a hypothetical → [☠︎︎](../☠︎︎/)
- Wild speculation that is a leap, not a busted claim → [🐉](../🐉/)

## File names

Short and source-identifying: `Author-Year-short-slug.ext` (or equivalent). Pair the claim and the falsifier in the name when useful. Example: `ATBC-1994-beta-carotene-smokers.pdf`.
