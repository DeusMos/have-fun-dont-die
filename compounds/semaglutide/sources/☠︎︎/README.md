# ☠︎︎ Sure, meaningful harm.

Established that this hurts people in a real way. Not a hypothetical. Not “may cause cancer” labeling. Bleach-for-COVID energy.

A document lives here because the **claim** in `report.md` is marked ☠︎︎. File by how the report marks the claim. If a claim is both false and known-harmful, the harm mark wins; the false efficacy can sit in the same statement.

## What belongs here

Sources that document sure, meaningful harm: poisonings, RCTs that showed harm, established toxicology. PDFs, html, markdown notes. The harm has to be real and meaningful, not a vibe.

## What does not belong here

- Settled textbook facts → [💯](../💯/)
- Uncontested published findings → [📚](../📚/)
- Preprints → [📜](../📜/)
- Live research disagreement → [🥼](../🥼/)
- Mechanistically coherent internet/clinic practice, not known-false → [🤔](../🤔/)
- Amateur fight → [🤼](../🤼/)
- Suspect / does not make sense, without established meaningful harm → [⛔](../⛔/)
- Wild speculation → [🐉](../🐉/)
- Potential / theoretical risk, precautionary labels, Prop-65 theater, animal-only scare stories without a human-meaning case, speculative downside, “could be harmful in some model”

## File names

Short and source-identifying: `Author-Year-short-slug.ext` (or equivalent). Example: `FDA-2020-bleach-ingestion-harm.md`.
