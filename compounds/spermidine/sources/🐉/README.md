# 🐉 Here be dragons. Wild speculation.

Forward-looking or mechanistic leaps with little or no direct evidence. Still say what the leap stands on.

A document lives here because the **claim** in `report.md` is marked 🐉. If there is no source, the report says “no source; inference from X” and tags 🐉. Do not dump a preprint here just because it has not been reviewed.

## What belongs here

Notes, slides, essays, and thin mechanistic writeups that the report treats as a leap. HTML, markdown, PDFs of those. The file can be thin; the mark is the point.

## What does not belong here

- Settled textbook facts → [💯](../💯/)
- Peer-reviewed papers/reviews not in a fight → [📚](../📚/)
- Preprints (unreviewed ≠ dragons) → [📜](../📜/)
- Papers in a live fight → [🥼](../🥼/)
- Internet/clinic practice that makes sense and is not known-false → [🤔](../🤔/)
- Amateur / biohacker fight → [🤼](../🤼/)
- Claims that do not make sense or are already contradicted → [⛔](../⛔/)

## File names

Short and source-identifying: `Author-Year-short-slug.ext` or `Topic-Year-short-slug.ext`. Example: `Ocampo-2016-partial-reprogramming-leap.md`.
