# 🤼 Amateur / biohacker fight.

Forum posts, Discord, blogs, clinic marketing — not research papers. Practitioners disagree. Cite the threads.

A document lives here because the **claim** in `report.md` is marked 🤼. This dir is only for amateurs and biohackers arguing on forums and the like. Never for research papers.

## What belongs here

Forum-thread captures, Discord exports, blog posts, clinic-marketing pages that document a split. HTML, markdown, PDF saves of those. File both sides.

## What does not belong here

- Settled textbook facts → [💯](../💯/)
- Peer-reviewed papers/reviews → [📚](../📚/)
- Preprints → [📜](../📜/)
- Research literature that disagrees (paper vs paper, preprint vs paper) → [🥼](../🥼/)
- Internet/clinic practice that is not a fight, and is not known to be false → [🤔](../🤔/)
- Circulating claims that do not make sense → [⛔](../⛔/)
- Wild speculation → [🐉](../🐉/)

## File names

Short and source-identifying: `Venue-Year-short-slug.ext` (or equivalent). Example: `RapamycinNews-2024-weekly-dose-split.md`.
