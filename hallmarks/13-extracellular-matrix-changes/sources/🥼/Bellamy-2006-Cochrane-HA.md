# Bellamy et al., 2006. Viscosupplementation for the treatment of osteoarthritis of the knee. Cochrane Database of Systematic Reviews.
https://doi.org/10.1002/14651858.CD005321.pub2 PMID 16625635
Used for: 🥼 An older Cochrane review (Bellamy 2006) reported moderate-to-large pain/function effects for some HA products vs placebo at 5–13 weeks; that is a symptom-class fight, not a disease-modifying ECM-restore result.
Mark: 🥼
N / effect / population / endpoint / duration: 76 trials, median Jadad 3. Heterogeneous product-level effects; 5–13 week pain improvement 28–54% from baseline in some placebo comparisons. OMERACT pain/function, not radiographic restore. Later large-blinded synthesis (Rutjes 2012) shrinks the effect.
Conflict if any: Cochrane review; older and more product-positive than Rutjes 2012.
