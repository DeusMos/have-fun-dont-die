# Coussens, Fingleton, and Matrisian, 2002. Matrix metalloproteinase inhibitors and cancer: trials and tribulations. Science.
https://doi.org/10.1126/science.1067100 PMID 11923508
Used for: 📚 Phase III cancer trials of broad MMP inhibitors (marimastat, prinomastat, BAY 12-9566 and class peers) showed no clinical efficacy and dose-limiting musculoskeletal syndrome; more than 50 MMP inhibitors entered trials and the class failed as a destiffen/remodel strategy.
Mark: 📚
N / effect / population / endpoint / duration: Review of 1997–2001 Phase III programs (lung, prostate, pancreas, brain, GI). No survival/progression benefit. MSS is the class toxicity. Hidalgo 2001 Oncogene (https://doi.org/10.1038/sj.onc.1204097) is the companion Phase III recap used in the same statement.
Conflict if any: Academic review of industry-failed programs.
