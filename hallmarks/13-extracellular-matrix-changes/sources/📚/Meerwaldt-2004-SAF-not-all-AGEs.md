# Meerwaldt et al., 2004. Simple non-invasive assessment of advanced glycation endproduct accumulation. Diabetologia.
https://doi.org/10.1007/s00125-004-1451-2 PMID 15168127
Used for: 📚 Meerwaldt 2004, from the group that built the AGE Reader, stated that not all AGEs fluoresce, that the autofluorescence ratio is a group reactivity that cannot quantify individual compounds, and that pathogenic non-fluorescent AGEs such as CML matter.
Mark: 📚
N / effect / population / endpoint / duration: Validation of forearm SAF vs skin-biopsy AGEs in diabetes and controls. Authors note fluorescent/non-fluorescent overlap and that SAF is not a diagnostic test given age dependence and overlap.
Conflict if any: Same group later commercialized AGE Reader via DiagnOptics; Smit is a DiagnOptics director in later papers.
