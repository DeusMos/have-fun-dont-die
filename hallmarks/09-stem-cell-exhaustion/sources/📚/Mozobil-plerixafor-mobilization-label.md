# Mozobil (plerixafor) USPI. DailyMed.

Used for: Plerixafor is labeled only to mobilize HSCs into blood for collection and subsequent autologous transplant in NHL/MM — mobilization for apheresis is not rejuvenation of an aged pool.
Mark: 📚
N / effect / population / endpoint / duration: Phase 3 Study 1 N=298 NHL; Study 2 N=302 MM. Plerixafor 0.24 mg/kg + filgrastim 10 µg/kg vs placebo + filgrastim. Endpoint=CD34+ cells collected for transplant. No aging indication.
