# Verdijk et al., 2014. Satellite cells in human skeletal muscle; from birth to old age. Age.
https://doi.org/10.1007/s11357-013-9583-2 PMID 24122288 PMC4039250
Used for: 📚 Human type II fibre satellite-cell content declines across adult aging and tracks type II fibre atrophy — the MuSC pool is measurable on biopsy and is smaller where regeneration/hypertrophy matter.
Mark: 📚
N / effect / population / endpoint / duration: N=165 biopsies: children <18 y n=13 (surgical muscles); vastus lateralis young adults 18–49 y n=50, older 50–69 y n=53, senescent 70–86 y n=49. Type II fibre size vs age r=−0.56 (P<0.001); type II SC content vs age r=−0.57 (P<0.001). Type I SC content not similarly reduced. Subgroup n=51 aged (71±6 y) had a 12-week RT arm that increased type II size and SC content — that arm is local load response, not a systemic restore product. Endpoint=fibre-type-specific Pax7 IHC.
