# 📜 Preprint. Posted, not peer-reviewed.

bioRxiv, medRxiv, arXiv, and the like. A real manuscript, no journal stamp yet.

A document lives here because the **claim** in `report.md` is marked 📜. Do not promote it to 📚 because the authors are famous. Do not dump it into 🤔 or 🐉 just because it has not been reviewed.

## What belongs here

Preprint PDFs, html, server pages, and markdown notes of posted-but-not-peer-reviewed manuscripts. The finding is not in a live literature fight.

## What does not belong here

- Settled, uncontested textbook facts → [💯](../💯/)
- Peer-reviewed journal papers/reviews whose finding is not in a fight → [📚](../📚/)
- Research literature that disagrees — published, preprint, or both → [🥼](../🥼/)
- Forums, clinics, newsletters, podcasts, self-experiments, protocols-in-the-wild → [🤔](../🤔/)
- Amateur / biohacker disagreements → [🤼](../🤼/)
- Circulating claims that do not make sense → [⛔](../⛔/)
- Mechanistic leaps with little or no direct evidence (a preprint is still a preprint) → [🐉](../🐉/)

## File names

Short and source-identifying: `Author-Year-short-slug.ext` (or equivalent). Example: `Gorbunova-2025-fucoidan-sirt6-biorxiv.pdf`.
