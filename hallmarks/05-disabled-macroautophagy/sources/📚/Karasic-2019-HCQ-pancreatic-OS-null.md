# Karasic et al., 2019. Effect of Gemcitabine and nab-Paclitaxel With or Without Hydroxychloroquine on Patients With Advanced Pancreatic Cancer. JAMA Oncology.
https://doi.org/10.1001/jamaoncol.2019.0684 NCT01506973 PMC6547080
Used for: Oncology treats autophagy as a tumor-support pathway to block: adding hydroxychloroquine 600 mg BID to gemcitabine/nab-paclitaxel did not improve 12-month overall survival in metastatic pancreatic cancer.
Mark: 📚
N / effect / population / endpoint / duration: Open-label phase 2, N=112 previously untreated metastatic/advanced PDAC (55 GA+HCQ / 57 GA). HCQ 600 mg PO BID continuous. Primary: 12-month OS 41% (95% CI 27–53) vs 49% (35–61). Median OS 11.1 vs 12.1 mo. Median PFS 5.7 vs 6.4 mo. ORR 38.2% vs 21.1% (P=0.047) without OS win. Grade 3/4 neutropenia 42.6% vs 22.6%; visual changes 5.6% vs 0. Cancer autophagy-inhibition, opposite direction from aging “activator stacks.”
Conflict if any: Academic SU2C-funded trial. HCQ is a lysosomal blocker, not an aging supplement.
