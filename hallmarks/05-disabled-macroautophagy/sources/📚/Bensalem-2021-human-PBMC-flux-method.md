# Bensalem et al., 2021. Measurement of autophagic flux in humans: an optimized method for blood samples. Autophagy.
https://doi.org/10.1080/15548627.2020.1846302 PMID 33164641 PMC8525931
Used for: 📚 Whole-blood chloroquine blockade plus PBMC LC3B-II measurement is a working human macroautophagy flux assay; leucine plus insulin ex vivo changed the signal, showing the method can register a nutritional perturbation.
Mark: 📚
N / effect / population / endpoint / duration: Method paper. Whole blood ± chloroquine, 37°C, 1 h, then PBMC LC3B-II. LC3B outperformed LC3A/C, p62, NBR1 in this setup. Intra-individual change shown with ex vivo leucine+insulin (exact donor N not extracted from the open HTML). This is a blood-cell flux method, not a whole-body or clinical autophagy-age score.
Conflict if any: Academic / SAHMRI. Same group later ran iTRE flux (2025).
