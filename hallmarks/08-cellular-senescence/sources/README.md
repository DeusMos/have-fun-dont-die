# sources/

One subdirectory per evidence mark. File a document in the dir that matches how the **claim** is marked in `report.md`. Do not upgrade because the finding would be cool. Do not downgrade because it is inconvenient.

Read the README in the dir you are filing into.

| Dir | Meaning |
|---|---|
| [💯](💯/) | Settled. Known and not contested. |
| [📚](📚/) | Published and peer-reviewed. |
| [📜](📜/) | Preprint. Posted, not peer-reviewed. |
| [🥼](🥼/) | Papers in a live fight. |
| [🤔](🤔/) | Guys on the internet said it, it makes sense, and it is not actively known to be false. |
| [🤼](🤼/) | Amateur / biohacker fight. |
| [⛔](⛔/) | Suspect. Does not make sense. |
| [☠︎︎](☠︎︎/) | Sure, meaningful harm. |
| [🐉](🐉/) | Here be dragons. Wild speculation. |

Marks and routing rules live in the repo `AGENTS.md`. Do not invent new meanings here.
