# Horvath, 2013. DNA methylation age of human tissues and cell types. Genome Biology.
https://doi.org/10.1186/gb-2013-14-10-r115 PMID 24138928
Used for: 📚 Ordinary human tissues accumulate age-associated DNA methylation change that a single 353-CpG elastic-net model reads as chronological age across 51 healthy tissue/cell types.
Mark: 📚
N / effect / population / endpoint / duration: N=7,844 non-cancer samples from 82 Illumina 27K/450K datasets, 51 tissues/cell types; training age correlation 0.97 / error 2.9 y; unbiased test correlation 0.96 / median absolute error 3.6 y; 353 clock CpGs (193 hyper-, 160 hypo-methylated with age); ES/iPS DNAm age near zero. Cross-sectional. Prediction accuracy is not causal drive.
